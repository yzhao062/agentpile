# Overview Figure Sources

`overview.html` is the source of `assets/overview.png`, and `render.py` checks its dataset counts against the manifests and renders it with headless Chrome. Every label, arrow and small diagram is drawn in the page; only the files below are pictures.

`pile.png`, the stack of record tiles in the centre, was made for this figure with OpenAI's image generation (through Codex), then cropped, resized and given a transparent background.

Third-party logos keep their upstream licenses and trademark rights; agentpile's Apache-2.0 license does not cover them. Each names the tool the figure points to. Phoenix, Inspect AI, Invariant Guardrails and networkx appear as text only.
